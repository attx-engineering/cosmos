# ##############################################################################
# Spacecraft simulation truth (SIM_SPACECRAFT)
# Truth state published by the WarpTwin Spacecraft assembly model, one instance per
# spacecraft in the sim. Not a flight app: this packet has no entry in a WarpOS build
# manifest, so CosmosUpdateCmdTlm.py does not generate it and it lives in this separate
# file to survive regeneration of tlm.txt.
# Base APID: 0x7F0  |  Instance 0-4 (one block per spacecraft)
# ##############################################################################
