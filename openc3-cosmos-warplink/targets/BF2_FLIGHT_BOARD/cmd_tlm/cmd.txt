COMMAND BF2_FLIGHT_BOARD STORAGE_MANAGER_CFDP BIG_ENDIAN " Uplink Packet, meant for holding all CFDP packets to be sent. NOT MEANT TO BE EDITED BY USERS, Warplink handles this."
  # Bare CFDP PDU -- no CCSDS wrapper, no separate outer CRC (the PDU's own
  # inner CRC, already baked into these bytes by the CFDP microservice, is
  # what CommandManager's generic packet-CRC check validates on receipt).
  # Unlike the telemetry side, the header can't be decomposed into individual
  # ID_ITEM/ITEM parameters here: those work for telemetry because COSMOS is
  # decoding already-known bytes, but for an outgoing command COSMOS would be
  # constructing bytes from each parameter's fixed default, which would
  # ignore the real header content (different per PDU type and per call)
  # already built into this field's value before cmd() is invoked.
  APPEND_PARAMETER  data_buffer                   0         STRING    ""        "Raw CFDP PDU, no CCSDS wrapper. array_length is the flight-side fixed buffer capacity (matches the 256-byte command read buffer in WarpPony::readCommand and the telemetry side's cfdp_packet) -- variable_length makes the COSMOS wire size match the real PDU exactly instead of always sending the full 256 bytes zero-padded, which otherwise piles up unconsumed padding in CommandManager's input buffer after every command."
